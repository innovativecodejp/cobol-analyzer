# prompt/

`specs/` への出力を生成するためのプロンプトを管理するディレクトリです。

## 用途

- ロードマップ（設計の方向性・計画を示すプロンプト）
- 実行プロンプト（`specs/` に仕様を出力するためのプロンプト）

ここに保存したプロンプトファイルの内容をコマンドとして実行するという運用を取ります。

---

## ファイル名規約

`working/` と同じ命名規則を使用します。

```
<working_date>_<sequence_no>_<title>.md
```

| フィールド | 説明 |
|---|---|
| `working_date` | 作成日（`yyyy-mm-dd` 形式） |
| `sequence_no` | 同一日付内の連番（01オリジン、2桁ゼロ埋め） |
| `title` | プロンプト内容を代表するタイトル（英小文字・ハイフン区切り推奨） |

### 例

```
2026-05-01_01_initial-roadmap.md
2026-05-01_02_cobol-structure-spec.md
2026-05-02_01_mdi-definition-spec.md
```
