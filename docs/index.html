このツールについて

  • 解析エンジン（.NET）が COBOL を AST 化し、CFG/DFG・6 指標から MDI（移行困難度指数）を算出。
  • プログラム間の静的 CALL 依存グラフと、MDI に基づく移行優先度ランキング・戦略提案。
  • 本デモは事前計算された静的成果物（JSON / Markdown / SVG）で構成され、サーバを必要としません。
